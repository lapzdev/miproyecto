# Proyecto: Travel Agency Page

Este proyecto consiste en la creación de una página web funcional para una agencia de viajes, cumpliendo con una serie de requisitos técnicos y de contenido para mejorar el SEO y la accesibilidad.

## 🎯 Objetivo
Construir una aplicación web que sea visualmente atractiva y cumpla con las historias de usuario definidas para un laboratorio de desarrollo web.

## 🛠️ Requisitos Técnicos (Historias de Usuario)

### Estructura HTML y SEO
- [ ] Declaración `<!DOCTYPE html>`.
- [ ] Elemento `<html>` con el atributo `lang="en"`.
- [ ] Elemento `<head>` con:
  - [ ] `meta charset="utf-8"`.
  - [ ] `<title>` con el texto "Travel Agency Page".
  - [ ] `<meta>` con una descripción breve para SEO.
- [ ] Elemento `<body>` correctamente estructurado y cerrado.

### Contenido de la Página
- [ ] Un único elemento `<h1>` para presentar los destinos.
- [ ] Un párrafo `<p>` introductorio debajo del `<h1>`.
- [ ] Sección de Paquetes:
  - [ ] Título `<h2>` con el texto "Packages".
  - [ ] Párrafo `<p>` introductorio sobre los paquetes.
  - [ ] Lista desordenada `<ul>` con dos elementos:
    - [ ] "Group Travels" (dentro de un enlace `<a>`).
    - [ ] "Private Tours" (dentro de un enlace `<a>`).
- [ ] Sección de Itinerarios:
  - [ ] Título `<h2>` con el texto "Top Itineraries".
  - [ ] Al menos tres elementos `<figure>`, cada uno con:
    - [ ] Un elemento `<a>` que contiene una imagen `<img>`.
    - [ ] Un elemento `<figcaption>` descriptivo.
    - [ ] Imágenes con atributos `src` válidos y `alt` apropiados.

### Enlaces y Atributos
- [ ] Todos los elementos `<a>` deben:
  - [ ] Tener `href="https://www.freecodecamp.org/learn"`.
  - [ ] Tener `target="_blank"`.

## 🚀 Pruebas de Calidad
El proyecto debe pasar todas las validaciones de estructura, accesibilidad (atributos `alt`) y cumplimiento de enlaces para considerarse completo.
