Crea una página de agencia de viajes
Construye una app que sea funcionalmente similar a este proyecto de ejemplo. Trata de no copiar el proyecto de ejemplo, dale tu propio estilo personal.

Objetivo: Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

Historias de usuario:

Debes tener una declaración DOCTYPE.
Debes tener un elemento html con lang configurado en en.
Debes tener un elemento head que contenga un elemento void meta con charset configurado en utf-8 y un title con el texto Travel Agency Page.
Debes tener una etiqueta meta en tu elemento head que contenga una breve descripción de tu sitio web para SEO.
Debes tener un elemento h1 para presentar tus destinos de viaje. Debe ser el único elemento h1 en tu página.
Debes tener un párrafo debajo del elemento h1 que introduzca las oportunidades de viaje.
Debes tener un elemento h2 con el texto Packages.
Debes tener un elemento p que introduzca brevemente los distintos paquetes.
Debes tener un elemento de lista desordenada con dos elementos de lista. Los dos elementos de lista deben tener el texto Group Travels y Private Tours, respectivamente. El texto de cada elemento de lista debe estar encerrado por un elemento ancla.
Debes tener un elemento h2 con el texto Top Itineraries.
Debes tener al menos tres elementos figure, cada uno conteniendo un elemento ancla y un elemento figcaption que describa la imagen de la figura.
Los tres elementos ancla deben tener un elemento img con un atributo alt apropiado y un atributo src configurado a una imagen válida como su contenido. Puedes usar -pg, https://cdn.freecodecamp.org/curriculum/labs/alps.jpg yhttps://cdn.freecodecamp.org/curriculum/labs/alps.jpg https://cdn.freecodecamp.org/curriculum/labs/sea.jpg si quieres.
Todos tus cinco elementos ancla deben tener un atributo href con el valor https://www.freecodecamp.org/learn y un atributo target con el valor _blank.
Pruebas:
Esperando:1. Su página de agencia de viajes debería tener una declaración !DOCTYPE html.
Esperando:2. Debes tener un elemento html con el atributo lang configurado a en.
Esperando:3. Su elemento html debe tener una etiqueta de cierre.
Esperando:4. Debes tener un elemento head dentro del elemento html.
Esperando:5. Tu elemento head debe tener una etiqueta de cierre.
Esperando:6. Debes tener un elemento title dentro de tu elemento head.
Esperando:7. Tu elemento title debe tener una etiqueta de cierre.
Esperando:8. Debería tener dos elementos meta dentro de su elemento head.
Esperando:9. Un elemento meta debería tener un atributo name con el valor de description y un atributo content no vacío.
Esperando:10. Un elemento meta debe tener su atributo charset configurado en utf-8.
Esperando:11. Tu elemento title debe tener el nombre de tu agencia de viajes.
Esperando:12. Debes tener un elemento body dentro de tu elemento html.
Esperando:13. Tu elemento body debe tener una etiqueta de cierre.
Esperando:14. Debes tener un elemento h1 para presentar tus destinos de viaje.
Esperando:15. Debes tener solo un elemento h1.
Esperando:16. Debes tener un elemento p debajo del elemento h1.
Esperando:17. Tu primer elemento p debe presentar las oportunidades de viaje.
Esperando:18. Tu primer elemento h2 debe tener el texto Packages.
Esperando:19. Debes tener un elemento p debajo de tu primer elemento h2.
Esperando:20. Tu segundo elemento p debe presentar brevemente los distintos paquetes.
Esperando:21. Debes tener un elemento de lista desordenada debajo de tu segundo elemento p.
Esperando:22. Debes tener dos elementos en tu lista desordenada.
Esperando:23. Ambos elementos de la lista deben contener un elemento ancla.
Esperando:24. El elemento ancla de tu primer elemento de lista debe envolver el texto Group Travels.
Esperando:25. El elemento ancla de tu segundo elemento de lista debe envolver el texto Private Tours.
Esperando:26. Debes tener un elemento h2 después de tu lista desordenada.
Esperando:27. Tu segundo elemento h2 debe tener el texto Top Itineraries.
Esperando:28. Debes tener al menos tres elementos figure.
Esperando:29. Cada elemento figure debe contener un elemento ancla como su primer elemento anidado.
Esperando:30. Cada elemento figure debe contener un elemento figcaption como su segundo elemento anidado.
Esperando:31. Cada figcaption debe contener algo de texto.
Esperando:32. Cada uno de los elementos a anidados en tus elementos figure debe contener una imagen.
Esperando:33. Cada elemento img debe tener un atributo src válido.
Esperando:34. Cada elemento img debe tener un atributo alt con un valor apropiado.
Esperando:35. Cada elemento a debe tener un atributo href con el valor https://www.freecodecamp.org/learn. No olvides los enlaces en los elementos de la lista.
Esperando:36. Cada elemento a debe tener un atributo target con el valor _blank. No olvides los enlaces en los elementos de la lista.
